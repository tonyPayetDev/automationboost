OmniRoute : Claude Code sans limite, gratuit — ce que c’est vraiment

Vérifié le 7 septembre 2026 sur le dépôt·~6 min·4 commandes

Tu as vu passer le reel : « Claude Code illimité et gratuit ». C’est vrai, et c’est faux, selon ce qu’on met derrière le mot gratuit. OmniRoute est un logiciel libre (licence MIT) qui tourne sur ta machine et se fait passer pour l’API d’Anthropic. Claude Code lui parle comme d’habitude ; lui, il envoie tes requêtes à l’un des 352 fournisseurs qu’il connaît — dont une bonne partie ont un palier gratuit. Quand l’un dit « quota atteint », il passe au suivant sans te couper. Voilà tout le génie du truc, et voilà aussi sa limite : ce n’est pas Claude qui te répond gratuitement, c’est un autre modèle, choisi parmi ceux qui ont encore du crédit.

En une phrase

OmniRoute te donne Claude Code l’outil (le terminal, les fichiers, les skills) sans payer Anthropic, mais avec le cerveau d’un modèle gratuit derrière. Pour du code de brouillon, des tests, des scripts jetables : oui. Pour ce qui part en prod chez un client : je garde Opus.

Les chiffres, tels qu’ils sont dans le README

Le reel parle de 200 fournisseurs, 1,6 milliard de tokens et 90 % d’économie. Le dépôt, lui, dit ceci le 7 septembre 2026 (les auteurs ré-auditent le catalogue toutes les deux semaines et préviennent que ça bouge dans les deux sens) :

  • 352 fournisseurs dans le catalogue (356 dans le bandeau d’accueil), 90+ paliers gratuits, 152 marqués « free » et 52 gratuits sans clé, pour de bon.
  • ~1,47 à 1,51 milliard de tokens gratuits par mois selon la version du README — un calcul « dédupliqué par pool », qui ne compte qu’une fois les fournisseurs qui partagent un même quota. Jusqu’à ~2,1 milliards le premier mois avec les crédits de bienvenue.
  • Compression RTK + Caveman : 15 à 95 % de tokens en moins, ~89 % en moyenne sur les sorties d’outils (logs, git, tests). Le code, les URL et le JSON ne sont jamais touchés.
  • Bascule automatique en 4 paliers : ton abonnement → ta clé API → les modèles pas chers → les gratuits. Trois couches de résilience (disjoncteur par fournisseur, refroidissement par clé, verrouillage par modèle).
  • Licence MIT, 62 000 étoiles, 550+ contributeurs, 1 300 modèles référencés.

Donc « 1,6 milliard » est arrondi vers le haut, « 200 fournisseurs » vers le bas, et « 90 % » est la moyenne, pas le plafond. Rien de scandaleux — mais autant citer les vrais.

Installation — trois commandes

Il faut Node.js sur ta machine. Ensuite :

npm install -g omniroute omniroute

Le serveur démarre sur http://localhost:20128 et ouvre un tableau de bord. Sans aucune clé, deux fournisseurs gratuits sont déjà branchés : tu peux tester tout de suite avec le modèle auto. Pour brancher Claude Code, la commande dédiée règle tout à ta place :

omniroute setup-claude omniroute launch

setup-claude écrit un profil Claude Code, launch ouvre Claude Code dessus en injectant le jeton. À la main, ce sont deux variables d’environnement : ANTHROPIC_BASE_URL pointée sur http://localhost:20128 (sans /v1) et ANTHROPIC_AUTH_TOKEN avec une clé OmniRoute ; le modèle se règle sur auto (ou auto/offline pour privilégier le fournisseur qui a le plus de marge de quota). Deux pièges relevés dans le wiki : les variables sont lues au démarrage, donc redémarre Claude Code après un changement ; et le jeton n’est jamais écrit dans le profil, il faut passer par launch ou l’exporter toi-même.

Où ajouter tes paliers gratuits

Dans le tableau de bord, /dashboard/free-tiers liste les fournisseurs, ce qu’ils donnent par mois et ce qu’il te reste. C’est là que tu colles tes clés Mistral, Gemini, Groq… Chaque clé ajoutée grossit ton réservoir. Le README publie la méthode de calcul dans docs/reference/FREE_TIERS.md.

Ce que le reel ne dit pas

  • Tes prompts partent chez le fournisseur qui répond. Sur un projet client, ça veut dire que du code confidentiel transite chez une dizaine de sociétés que tu n’as pas choisies une à une. Le catalogue d’OmniRoute marque lui-même 15 fournisseurs « à éviter » pour leurs conditions d’utilisation.
  • Le modèle change en cours de route. Une bascule, c’est un autre modèle qui reprend ta session : le style, la rigueur et la mémoire du contexte ne sont pas les mêmes. Tu le verras surtout sur les tâches longues.
  • Les paliers gratuits sont des cadeaux révocables. Un fournisseur ferme son offre, le réservoir baisse. Les auteurs le disent noir sur blanc.
  • Ce n’est pas un abonnement Claude gratuit. Si tu veux Opus, tu passes par ton abonnement ou ta clé — OmniRoute les met en palier 1 et 2 justement pour ça.

Mon usage, cash

Depuis La Réunion, l’abonnement Max à plus de 100 € par mois pique, et les jours où je fais tourner trois vidéos et deux workflows, je tape le plafond avant midi. Je vois OmniRoute comme une roue de secours : Claude Code reste branché sur mon abonnement en priorité, et quand la limite tombe, la session continue sur un modèle gratuit pour le boulot mécanique — renommer, tester, écrire des fixtures, résumer un log. Le raisonnement d’architecture et tout ce qui part chez un client attendent le retour d’Opus. Ça, c’est le vrai gain : ne plus perdre la session, pas coder gratuitement toute la journée.

  1. Installe et lance omniroute — 2 min.
  2. Colle deux ou trois clés gratuites (Mistral, Gemini, Groq) dans le tableau de bord — 10 min, c’est ce qui remplit le réservoir.
  3. Branche Claude Code avec omniroute setup-claude puis omniroute launch, modèle auto — 1 min.
  4. Regarde l’en-tête X-OmniRoute-Decision dans le tableau de bord : il te dit quel fournisseur a répondu à chaque requête. Le jour où tu vois passer un nom que tu ne connais pas sur un projet client, coupe-le.
