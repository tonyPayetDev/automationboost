Ton analyse Instagram + TikTok, 100% automatique chaque lundi

n8n + Telegram · Automatisation réseaux · Niveau débutant

Le lundi matin, avant de checker tes mails, tu ouvres Instagram Insights, puis TikTok Analytics, tu notes les chiffres qui comptent, tu essaies de te souvenir quel post a le mieux marché la semaine passée pour le refaire. Dix minutes qui reviennent chaque semaine, et que tu oublies un lundi sur trois.

Ce workflow le fait à ta place. Il tourne tout seul chaque lundi à 8h, va chercher tes posts Instagram et tes vidéos TikTok de la semaine, calcule le meilleur, le pire, et l'engagement moyen, puis t'envoie le résumé directement sur Telegram — avec une recommandation concrète pour la semaine suivante.

Ce qu'il te faut

  • n8n (auto-hébergé ou cloud)
  • Un compte Instagram professionnel connecté à l'API Graph de Meta
  • Un accès à l'API TikTok (Business API, ou tout export de tes stats vidéo)
  • Un bot Telegram pour recevoir le rapport (2 minutes à créer via @BotFather)

L'architecture, en quatre étapes

1

Un déclencheur planifié chaque lundi à 8h.

2

Deux appels en parallèle : les posts Instagram récents et les vidéos TikTok récentes.

3

Un nœud Code fusionne les deux, calcule l'engagement (likes + commentaires) de chaque post, trie, et garde le meilleur, le pire, et la moyenne.

4

Le résumé part sur Telegram — lisible en dix secondes, café à la main.

Pourquoi Instagram et TikTok en parallèle, pas l'un après l'autre

La tentation, c'est de chaîner les deux appels API l'un derrière l'autre. Le problème : si l'appel Instagram renvoie 20 posts, l'appel TikTok qui suit se déclencherait 20 fois au lieu d'une seule — un bug classique de multiplication d'items. La solution ici : deux branches parallèles depuis le même déclencheur, réunies par un nœud Merge juste avant le calcul.

// Nœud Code — calcule meilleur / pire / moyenne sur les deux plateformes const items = $input.all(); const posts = []; for (const item of items) { const raw = item.json.data || []; for (const p of raw) { const likes = p.like_count ?? p.view_count ?? 0; const comments = p.comments_count ?? p.comment_count ?? 0; posts.push({ id: p.id, engagement: likes + comments }); } } posts.sort((a, b) => b.engagement - a.engagement); const best = posts[0]; const worst = posts[posts.length - 1]; const avg = posts.reduce((s, p) => s + p.engagement, 0) / posts.length;
⚠ Le piège du dimanche soir

Si le déclencheur tourne un lundi férié où tu n'as rien publié la semaine passée, l'appel API renvoie une liste vide. C'est normal, pas une panne : laisse le workflow s'arrêter proprement plutôt que de forcer un résultat vide dans Telegram — il reprendra son rythme la semaine suivante.

Ce à quoi t'attendre

  • Un message Telegram chaque lundi à 8h, sans rien ouvrir
  • Le meilleur et le pire post de la semaine, identifiés automatiquement
  • Une recommandation concrète à appliquer dès le lundi
  • Zéro tableau à ouvrir, zéro copier-coller
💡 Pour aller plus loin

Une fois le rapport fiable, remplace le message Telegram brut par un appel à un modèle IA qui rédige la recommandation en une phrase plutôt qu'un chiffre — c'est la même architecture, un nœud en plus avant l'envoi.
