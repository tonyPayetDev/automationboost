Le prompt exact (copiable)

Ouvre Seedance 2.5, colle ce prompt, génère. Les commentaires // indiquent les beats de découpage si ton outil génère en plusieurs clips (ou si tu veux les enchaîner toi-même).

// SEEDANCE 2.5 — CLIP 1/3 — 0-10 s Keynote cinématique, présentation continue de 30 s. SCÈNE : scène premium, auditorium noir, écran LED géant. Un présentateur en tenue noire, spot blanc, lumière volumétrique. CAMÉRA : plan très large, l'écran géant domine, push-in lent. Écran : « 1 PROMPT. » Il regarde l'audience : « Un seul prompt… » « …et vous obtenez votre vidéo complète. » L'écran devient l'interface animée VideoBoost. // CLIP 2/3 — 10-20 s — continuation directe Même présentateur, même visage, même scène, même caméra. « Et automatiquement… » l'écran s'anime. Cinq concepts apparaissent l'un après l'autre : VOIX · MOTION · STYLE · SOUS-TITRES · HOOK Chaque mot apparaît quand il le prononce, démo visuelle à l'appui. Finition ultra-léchée, lancement produit de classe mondiale. // CLIP 3/3 — 20-30 s — continuation directe Les cinq éléments fusionnent en une seule vidéo. « Vous ne créez plus une vidéo étape par étape. » L'écran : 1 PROMPT → 1 VIDÉO « Vous donnez une idée… » « …VideoBoost s'occupe du reste. » Révélation finale : titre VIDEOBOOST — 1 PROMPT. 1 VIDÉO. // identité verrouillée · zéro morphing · zéro coupe

Mode d'emploi (4 étapes)

  • 1. Ouvre Seedance 2.5 (ex. via Higgsfield) et crée une génération vidéo à partir de texte — format 9:16 si c'est pour les réseaux sociaux.
  • 2. Colle le prompt exact ci-dessus. Ne le raccourcis pas : chaque ligne porte une instruction (scène, caméra, dialogues, éléments à l'écran).
  • 3. Vérifie la durée : le prompt vise ~30 s. Ajuste le nombre de clips ou la durée de sortie si ton outil demande un découpage.
  • 4. Génère, regarde, itère : si un détail dérange (fond, timing des mots), modifie UNE phrase et relance — le reste reste stable grâce aux consignes « même présentateur / même scène / même caméra ».
💡 Le piège à éviter

Ne supprime jamais les lignes « même présentateur, même visage, même scène, même caméra » entre les clips. C'est exactement ce qui verrouille l'identité et empêche le morphing (le visage qui change d'un clip à l'autre) — le défaut n°1 des vidéos IA multi-plans.
