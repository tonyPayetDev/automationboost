Comment utiliser ce workflow

Ce workflow n8n est prêt à l'emploi. Voici les étapes pour le déployer rapidement :

  • Ouvrez votre instance n8n et cliquez sur Workflows → Import from File
  • Sélectionnez le fichier JSON téléchargé — le workflow apparaît automatiquement
  • Configurez vos identifiants pour chaque service utilisé (n8n, X/Twitter API, OpenAI)
  • Testez le workflow avec le bouton Execute Workflow
  • Activez-le pour qu'il tourne en automatique

Automatise votre présence sur X (Twitter) : création de contenu avec l'IA, planification et publication sans effort. Idéal pour les créateurs de contenu et freelances.
