Brancher Claude Opus à tes automatisations n8n

n8n · API Anthropic · Niveau intermédiaire

Tu as commenté OPUS sous la vidéo : voilà exactement comment brancher le dernier modèle de Claude dans tes workflows n8n, à la place de ton ancien modèle. Pas de teaser, la config complète.

C'est quoi Opus, exactement

Opus, c'est la famille de modèles la plus puissante d'Anthropic (les créateurs de Claude). Le dernier en date s'appelle Opus 5 ; la génération juste avant, Opus 4.8, tourne encore très bien et coûte pareil. Les deux frôlent le haut de gamme sur le code et le raisonnement.

Le vrai atout pour tes automatisations : une fenêtre de contexte énorme (1 million de tokens), active par défaut. Tu peux lui envoyer un projet de code entier, ou cent pages de documents d'un coup, et il garde tout en tête pour répondre. C'est pour ça qu'il fait la différence sur les tâches longues.

Étape 1 — Récupérer ta clé API et la stocker en credential

Crée une clé API dans ta console Anthropic (console.anthropic.com, section API Keys). Ne la colle jamais en clair dans un node.

Dans n8n : ouvre un node HTTP Request, section Authentication → Generic Credential Type → Header Auth. Crée une credential où :

  • Name = x-api-key
  • Value = ta clé (sk-ant-...)

La clé vit dans le coffre de credentials n8n, pas dans le workflow. Tu peux exporter/partager le workflow sans fuiter le secret.

Étape 2 — Le node HTTP Request vers l'API Anthropic

Configure le node comme ceci :

  • Method : POST
  • URL : https://api.anthropic.com/v1/messages
  • Authentication : la credential Header Auth de l'étape 1 (x-api-key)
  • Headers : ajoute anthropic-version = 2023-06-01
  • Body : JSON (voir ci-dessous)

Le body minimal, à coller dans le champ JSON du node :

{ "model": "claude-opus-4-8", "max_tokens": 1024, "messages": [ { "role": "user", "content": "Résume ce texte en 3 points : {{ $json.texte }}" } ] }

La réponse arrive dans content[0].text — tu la récupères avec une expression n8n du type {{ $json.content[0].text }} dans le node suivant.

Quel modèle mettre dans "model"

  • claude-opus-4-8 — Opus 4.8, valeur sûre, excellent rapport qualité/prix
  • claude-opus-5 — la toute dernière génération Opus, si tu veux le maximum

Tu changes juste la chaîne de caractères pour basculer d'un modèle à l'autre : le reste du node ne bouge pas.

⚠ Le piège que tout le monde oublie

Sans le header anthropic-version: 2023-06-01, l'API répond 400 Bad Request — et n8n te sort une erreur cryptique qui n'a rien à voir. Ce header est obligatoire sur chaque appel. Ajoute-le une fois pour toutes. Autre point : pour profiter des gros contextes (le projet entier, les 100 pages), pense à monter le max_tokens et à allonger le timeout du node HTTP Request — sinon n8n coupe l'appel avant la réponse. Et garde en tête que plus tu envoies de contexte, plus l'appel coûte cher : les gros contextes se facturent au token.

Ce à quoi t'attendre

  • Un modèle branché dans n8n en un seul node HTTP Request, sans plugin
  • La différence se voit direct sur les tâches longues (résumés massifs, analyse de code, tri de gros volumes)
  • Un basculement d'un modèle à l'autre en changeant une seule ligne
