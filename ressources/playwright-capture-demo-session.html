Capturer une Démo Réelle avec Playwright
et les Cookies de Session

Playwright + Xvfb vous permet d'enregistrer une vraie interaction sur votre site — navigation, clics, remplissage de formulaires — sans jamais perdre votre session. Voici le guide complet pour rester connecté tout au long de la capture et automatiser vos démos.

Playwright Xvfb Node.js n8n Cloudflare R2 FFmpeg

Pipeline de capture

🔑 Sauvegarde des cookies
→
🖥 Xvfb headless display
→
🎭 Playwright scénario
→
🎞 FFmpeg → MP4
→
☁️ Upload R2

Pourquoi gérer les cookies de session ?

Par défaut, chaque exécution Playwright ouvre un navigateur vierge — aucun cookie, aucune session. Si votre démo se passe dans une zone authentifiée (dashboard, espace client, back-office), vous êtes déconnecté dès le premier chargement de page.

La solution : sauvegarder l'état de session (storageState) après une connexion manuelle ou automatique, puis le réinjecter à chaque capture. Playwright stocke cookies + localStorage dans un simple fichier JSON.

💡 Ce que ça permet

Enregistrer des démos dans votre application réelle, avec vos vraies données, en restant connecté — sans intervention humaine à chaque run.

Étape 1 — Installation de l'environnement

1

Installer Playwright et les navigateurs

npm install playwright npx playwright install chromium
2

Installer Xvfb (Linux) pour un display virtuel

Xvfb crée un écran virtuel — indispensable pour enregistrer une vidéo en headful (sans fenêtre physique visible).

sudo apt-get install -y xvfb ffmpeg

Étape 2 — Sauvegarder les cookies de session

Lancez une session manuelle ou automatisée, connectez-vous, puis sauvegardez l'état avec context.storageState().

// save-session.js const { chromium } = require('playwright'); (async () => { const browser = await chromium.launch({ headless: false }); const context = await browser.newContext(); const page = await context.newPage(); // Connexion manuelle : naviguez, connectez-vous await page.goto('https://votre-site.com/login'); // --> attendez la connexion manuelle ici <-- // Sauvegarde de la session (cookies + localStorage) await context.storageState({ path: 'session.json' }); console.log('✅ Session sauvegardée dans session.json'); await browser.close(); })();
⚡ Automatiser la connexion

Remplacez la connexion manuelle par page.fill() et page.click() sur le formulaire de login. La session est ensuite réutilisable pour toutes vos captures.

Étape 3 — Lancer Xvfb et enregistrer la démo

Xvfb expose un display virtuel (:99). Playwright ouvre le navigateur en mode headful sur ce display. FFmpeg capture les frames directement depuis le serveur X.

// capture-demo.js const { chromium } = require('playwright'); const { execSync, spawn } = require('child_process'); (async () => { // 1. Démarrer Xvfb const xvfb = spawn('Xvfb', [':99', '-screen', '0', '1920x1080x24']); process.env.DISPLAY = ':99'; await new Promise(r => setTimeout(r, 1000)); // attendre le display // 2. Démarrer l'enregistrement FFmpeg const ffmpeg = spawn('ffmpeg', [ '-f', 'x11grab', '-r', '25', '-s', '1920x1080', '-i', ':99', '-c:v', 'libx264', '-preset', 'ultrafast', '-y', 'demo-output.mp4' ]); // 3. Lancer Playwright avec la session sauvegardée const browser = await chromium.launch({ headless: false, args: ['--no-sandbox', '--disable-setuid-sandbox'] }); const context = await browser.newContext({ storageState: 'session.json', // <-- réinjection de la session viewport: { width: 1920, height: 1080 } }); const page = await context.newPage(); // 4. Scénario de démo await page.goto('https://votre-site.com/dashboard'); await page.waitForLoadState('networkidle'); await page.waitForTimeout(2000); // pause visuelle await page.click('[data-testid="btn-nouveau-projet"]'); await page.fill('input[name="titre"]', 'Mon projet démo'); await page.waitForTimeout(1500); await page.click('[data-testid="btn-sauvegarder"]'); await page.waitForTimeout(2000); // 5. Fin de la capture await browser.close(); ffmpeg.kill('SIGINT'); xvfb.kill(); await new Promise(r => setTimeout(r, 1000)); console.log('✅ Vidéo enregistrée : demo-output.mp4'); })();
⚠ Points d'attention

Certains sites renouvellent les tokens CSRF à chaque page. Si votre session expire rapidement, ajoutez une logique de reconnexion automatique avant chaque capture.

Étape 4 — Orchestrer avec n8n

Plutôt que de lancer le script manuellement, encapsulez-le dans un nœud Execute Command de n8n. Vous pouvez ainsi déclencher la capture depuis un webhook, un planning, ou n'importe quel trigger.

# Dans le nœud "Execute Command" de n8n DISPLAY=:99 xvfb-run --auto-servernum --server-args="-screen 0 1920x1080x24" \ node capture-demo.js
🔄 Pipeline n8n complet

Webhook → Execute Command (capture) → HTTP Request (upload R2) → Supabase (sauvegarde URL) → Notification Telegram

Étape 5 — Upload sur Cloudflare R2

Après la capture, uploadez la vidéo sur R2 avec le SDK AWS ou via une requête HTTP directe. R2 génère une URL publique persistante que vous stockez en Supabase.

// upload-r2.js const { S3Client, PutObjectCommand } = require('@aws-sdk/client-s3'); const fs = require('fs'); const client = new S3Client({ region: 'auto', endpoint: 'https://<ACCOUNT_ID>.r2.cloudflarestorage.com', credentials: { accessKeyId: process.env.R2_ACCESS_KEY, secretAccessKey: process.env.R2_SECRET_KEY } }); const videoBuffer = fs.readFileSync('demo-output.mp4'); const key = `demos/${Date.now()}-demo.mp4`; await client.send(new PutObjectCommand({ Bucket: 'email', Key: key, Body: videoBuffer, ContentType: 'video/mp4', ACL: 'public-read' })); const publicUrl = `https://assets.automatisationboost.com/${key}`; console.log('URL publique :', publicUrl);

Étape 6 — Sauvegarder l'URL en Supabase

// supabase-save.js const { createClient } = require('@supabase/supabase-js'); const supabase = createClient(process.env.SUPABASE_URL, process.env.SUPABASE_KEY); const { data, error } = await supabase .from('demo_captures') .insert({ url: publicUrl, created_at: new Date().toISOString(), titre: 'Démo dashboard', duree_secondes: 30 }); if (!error) console.log('✅ URL sauvegardée en base');

Checklist de mise en production

  • ✅ session.json régénéré automatiquement avant expiration
  • ✅ Xvfb lancé avec --auto-servernum pour éviter les conflits de display
  • ✅ FFmpeg encode en H.264 (libx264) pour compatibilité maximale
  • ✅ Timeouts généreux (waitForLoadState('networkidle')) pour les sites lents
  • ✅ Variable d'environnement DISPLAY=:99 injectée avant le process node
  • ✅ Logs de chaque étape pour debug en cas d'échec dans n8n
  • ✅ Nettoyage des fichiers temporaires après chaque run
