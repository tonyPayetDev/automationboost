Le CLAUDE.md du créateur de Claude Code

Claude Code·Workflow·Niveau intermédiaire

Le fichier CLAUDE.md est la mémoire permanente de Claude Code dans ton projet. C'est lui qui indique à l'IA comment travailler avec ton codebase, quelles conventions respecter, quels outils utiliser. Boris Cherny, le créateur de Claude Code chez Anthropic, a partagé le sien — et c'est une mine d'informations.

C'est quoi un CLAUDE.md ?

Quand tu lances Claude Code dans un dossier, il lit automatiquement le CLAUDE.md à la racine du projet. Ce fichier contient tes instructions persistantes : stack tech, patterns de code préférés, commandes importantes, règles de nommage, contexte métier.

Sans lui, Claude repart de zéro à chaque session. Avec lui, il connaît ton projet comme un dev senior qui travaille dessus depuis des mois.

Ce que contient celui de Boris Cherny

  • Les commandes de build, test et lint à toujours utiliser avant de committer
  • Les conventions de style de code (TypeScript strict, gestion des imports)
  • Les patterns à éviter et ceux à privilégier dans ce codebase
  • Les instructions sur comment poser des questions et clarifier avant d'agir
  • La règle de ne jamais modifier des fichiers hors du scope demandé
💡 Pourquoi c'est précieux

Voir le CLAUDE.md de celui qui a conçu l'outil te donne les bonnes pratiques directement depuis la source. Tu comprends comment l'outil est pensé pour être utilisé.

Structure recommandée pour ton propre CLAUDE.md

# CLAUDE.md ## Stack technique - Framework : Next.js 14 App Router - Style : Tailwind CSS - BDD : PostgreSQL via Prisma ## Commandes importantes - `npm run dev` — lancer en local - `npm run test` — tests unitaires - `npm run build` — vérifier avant deploy ## Conventions - Composants en PascalCase - Hooks préfixés par `use` - Pas de `any` TypeScript ## Règles - Toujours lire le fichier avant de le modifier - Demander confirmation avant de supprimer du code

Où placer le fichier

  • CLAUDE.md à la racine = instructions globales du projet
  • src/CLAUDE.md = instructions spécifiques au code source
  • ~/.claude/CLAUDE.md = règles globales pour tous tes projets
⚡ Conseil pro

Commence par un CLAUDE.md minimal, puis enrichis-le au fil des sessions. Chaque fois que Claude fait une erreur de convention, ajoute une règle pour que ça n'arrive plus jamais.
