Capturer une démo réelle du site avec Playwright + cookies de session

Le skill Playwright de Claude Code permet de piloter un navigateur réel, de s'authentifier, de conserver la session entre les pages — et de capturer chaque interaction en vidéo ou en screenshots. Voici comment ça fonctionne concrètement sur automatisationboost.com.

Pourquoi Playwright et pas un simple scroll ?

Un scroll basique capture une page statique. Une démo réelle, c'est autre chose : connexion à un compte, navigation entre pages, clic sur des boutons, remplissage de formulaires — exactement ce que voit un utilisateur authentifié.

Playwright pilote un vrai Chromium (ou Firefox). Combiné à Xvfb (X Virtual FrameBuffer), il tourne en mode headless sur serveur Linux sans interface graphique. FFmpeg enregistre l'écran en temps réel pour produire une vidéo MP4 propre.

💡 Cas d'usage clé

Générer automatiquement des vidéos de démo de votre SaaS à chaque déploiement, ou créer des tutoriels qui montrent une vraie navigation — pas une maquette.

Étape 1 — Installer les dépendances

Sur un serveur Ubuntu/Debian (ou dans un container Docker) :

bash — installation
# Xvfb pour l'écran virtuel
apt-get install -y xvfb x11-utils

# Playwright + Chromium
npm install playwright
npx playwright install chromium
npx playwright install-deps chromium

# FFmpeg pour l'enregistrement vidéo
apt-get install -y ffmpeg

Étape 2 — Démarrer Xvfb et préparer l'écran virtuel

Xvfb crée un écran X11 virtuel en mémoire. Playwright s'y branche, FFmpeg y lit les pixels pour enregistrer.

bash — lancement Xvfb
# Démarrer un écran virtuel 1920x1080 sur le display :99
Xvfb :99 -screen 0 1920x1080x24 -ac &
export DISPLAY=:99

# Vérifier que l'écran est actif
xdpyinfo -display :99 | grep dimensions

Étape 3 — Charger les cookies de session

Pour naviguer en tant qu'utilisateur connecté, il faut injecter les cookies de session dans Playwright avant d'ouvrir la première page. Deux approches :

Option A — Cookies exportés manuellement

Exportez vos cookies depuis DevTools (Network → Copy as cURL ou extension EditThisCookie), puis chargez-les :

JavaScript — chargement cookies
const { chromium } = require('playwright');

// Cookies exportés depuis le navigateur
const SESSION_COOKIES = [
  {
    name: 'session_token',
    value: 'eyJhbGc...',          // votre token
    domain: 'automatisationboost.com',
    path: '/',
    httpOnly: true,
    secure: true,
    sameSite: 'Lax'
  },
  {
    name: 'csrf_token',
    value: 'abc123...',
    domain: 'automatisationboost.com',
    path: '/'
  }
];

const browser = await chromium.launch({
  headless: false,          // false car on utilise Xvfb
  args: ['--no-sandbox', '--disable-setuid-sandbox']
});

const context = await browser.newContext({
  viewport: { width: 1920, height: 1080 }
});

// Injection des cookies AVANT la navigation
await context.addCookies(SESSION_COOKIES);

const page = await context.newPage();
await page.goto('https://automatisationboost.com/acces');

// Vérifier qu'on est bien connecté
const isLoggedIn = await page.locator('[data-user]').isVisible();
console.log('Connecté :', isLoggedIn);

Option B — Connexion via le formulaire (plus robuste)

Playwright remplit le formulaire de login et Playwright persiste automatiquement le cookie de session :

JavaScript — login automatique
async function login(page) {
  await page.goto('https://automatisationboost.com/acces');
  await page.fill('input[type="email"]', process.env.DEMO_EMAIL);
  await page.fill('input[type="password"]', process.env.DEMO_PASSWORD);
  await page.click('button[type="submit"]');
  await page.waitForURL('**/dashboard**');

  // Sauvegarder le state (cookies + localStorage) pour réutilisation
  await page.context().storageState({ path: './session.json' });
}

// Réutiliser la session sauvegardée au prochain lancement
const context = await browser.newContext({
  storageState: './session.json'   // session persistée
});
💡 storageState = gold standard

La méthode storageState de Playwright sauvegarde cookies + localStorage en un seul fichier JSON. Réutilisez ce fichier pour toutes vos captures sans vous reconnecter à chaque fois.

Étape 4 — Scénario de navigation réelle

Un scénario de démo crédible sur automatisationboost.com : accueil → ressources → formation → espace membre.

JavaScript — scénario complet
async function runDemoScenario(page) {

  // 1. Page d'accueil — laisser les animations se jouer
  await page.goto('https://automatisationboost.com', {
    waitUntil: 'networkidle'
  });
  await page.waitForTimeout(2000);
  await page.evaluate(() => window.scrollTo({ top: 500, behavior: 'smooth' }));
  await page.waitForTimeout(1500);

  // 2. Clic sur "Ressources" dans la navigation
  await page.click('a[href*="ressources"]');
  await page.waitForLoadState('networkidle');
  await page.waitForTimeout(2000);

  // 3. Hover sur une carte ressource pour montrer l'interactivité
  const firstCard = page.locator('.ressource-card').first();
  await firstCard.hover();
  await page.waitForTimeout(1000);

  // 4. Navigation vers la formation
  await page.goto('https://automatisationboost.com/formation.html', {
    waitUntil: 'networkidle'
  });
  await page.waitForTimeout(2000);
  await page.evaluate(() => window.scrollTo({ top: 800, behavior: 'smooth' }));
  await page.waitForTimeout(1500);

  // 5. Espace membre (authentifié)
  await page.goto('https://automatisationboost.com/acces.html', {
    waitUntil: 'networkidle'
  });
  await page.waitForTimeout(3000);
}

Étape 5 — Enregistrer la vidéo avec FFmpeg

FFmpeg capture l'écran Xvfb en temps réel pendant que Playwright navigue. On lance les deux en parallèle :

JavaScript — capture vidéo complète
const { spawn } = require('child_process');
const path = require('path');

async function captureDemo() {
  const outputFile = `demo-${Date.now()}.mp4`;

  // Lancer FFmpeg en arrière-plan
  const ffmpeg = spawn('ffmpeg', [
    '-f', 'x11grab',
    '-r', '30',                        // 30 fps
    '-s', '1920x1080',
    '-i', ':99.0',                     // display Xvfb
    '-vcodec', 'libx264',
    '-pix_fmt', 'yuv420p',
    '-preset', 'fast',
    '-crf', '23',
    '-y', outputFile
  ]);

  // Lancer le navigateur et le scénario
  const browser = await chromium.launch({
    headless: false,
    args: ['--no-sandbox', '--display=:99']
  });
  const context = await browser.newContext({
    viewport: { width: 1920, height: 1080 },
    storageState: './session.json'    // session persistée
  });
  const page = await context.newPage();

  await runDemoScenario(page);

  // Stopper FFmpeg proprement (signal SIGINT = fin d'encodage)
  ffmpeg.stdin.write('q');
  await new Promise(resolve => ffmpeg.on('close', resolve));

  await browser.close();
  console.log(`✅ Vidéo générée : ${outputFile}`);
  return outputFile;
}

Étape 6 — Scénario complet en un seul fichier

Le script autonome qui enchaîne toutes les étapes :

JavaScript — capture-demo.js (script complet)
#!/usr/bin/env node
// capture-demo.js — Démo authentifiée Playwright + Xvfb + FFmpeg

const { chromium } = require('playwright');
const { spawn, execSync } = require('child_process');
const fs = require('fs');

const TARGET_URL  = 'https://automatisationboost.com';
const DISPLAY     = ':99';
const RESOLUTION  = '1920x1080';
const SESSION_FILE = './session.json';
const OUTPUT      = `./demo-${Date.now()}.mp4`;

// 1. Démarrer Xvfb
execSync(`Xvfb ${DISPLAY} -screen 0 ${RESOLUTION}x24 -ac &`);
process.env.DISPLAY = DISPLAY;

// 2. Lancer FFmpeg
const ffmpeg = spawn('ffmpeg', [
  '-f', 'x11grab', '-r', '30', '-s', RESOLUTION,
  '-i', `${DISPLAY}.0`,
  '-vcodec', 'libx264', '-pix_fmt', 'yuv420p',
  '-preset', 'fast', '-crf', '23', '-y', OUTPUT
], { stdio: ['pipe', 'inherit', 'inherit'] });

(async () => {
  const browser = await chromium.launch({
    headless: false,
    args: ['--no-sandbox', '--disable-setuid-sandbox',
           '--window-size=1920,1080']
  });

  const ctxOpts = { viewport: { width: 1920, height: 1080 } };
  if (fs.existsSync(SESSION_FILE)) {
    ctxOpts.storageState = SESSION_FILE;   // session persistée
  }

  const ctx  = await browser.newContext(ctxOpts);
  const page = await ctx.newPage();

  // Se connecter si pas de session sauvée
  if (!fs.existsSync(SESSION_FILE)) {
    await page.goto(`${TARGET_URL}/acces.html`);
    await page.fill('#email', process.env.DEMO_EMAIL);
    await page.fill('#password', process.env.DEMO_PASSWORD);
    await page.click('button[type=submit]');
    await page.waitForTimeout(2000);
    await ctx.storageState({ path: SESSION_FILE });
  }

  // Scénario de navigation réelle
  await page.goto(TARGET_URL, { waitUntil: 'networkidle' });
  await page.waitForTimeout(2500);
  await page.evaluate(() => window.scrollTo({ top: 600, behavior: 'smooth' }));
  await page.waitForTimeout(2000);
  await page.click('a[href*="ressources"]');
  await page.waitForLoadState('networkidle');
  await page.waitForTimeout(2500);
  await page.goto(`${TARGET_URL}/formation.html`, { waitUntil: 'networkidle' });
  await page.waitForTimeout(3000);
  await page.evaluate(() => window.scrollTo({ top: 900, behavior: 'smooth' }));
  await page.waitForTimeout(2000);

  await browser.close();

  // Stopper FFmpeg
  ffmpeg.stdin.write('q\n');
  await new Promise(r => ffmpeg.on('close', r));

  console.log(`✅ Vidéo : ${OUTPUT}`);
})();

Gestion avancée des cookies

Renouveler la session expirée automatiquement

JavaScript — refresh session
async function ensureSession(page, ctx) {
  await page.goto('https://automatisationboost.com/acces.html');

  // Vérifier si la session est encore valide
  const isExpired = await page.locator('.login-form').isVisible();

  if (isExpired) {
    console.log('Session expirée, reconnexion...');
    await page.fill('#email', process.env.DEMO_EMAIL);
    await page.fill('#password', process.env.DEMO_PASSWORD);
    await page.click('button[type=submit]');
    await page.waitForTimeout(2000);
    // Mettre à jour le fichier session
    await ctx.storageState({ path: './session.json' });
  }
}

Bloquer les ressources inutiles pour accélérer la capture

JavaScript — interception réseau
// Bloquer analytics, publicités et fonts tiers
await page.route('**/*', route => {
  const url = route.request().url();
  const blocked = [
    'google-analytics', 'gtag', 'hotjar',
    'facebook.net', 'doubleclick'
  ];
  if (blocked.some(b => url.includes(b))) {
    route.abort();
  } else {
    route.continue();
  }
});
⚠️ Sécurité

Ne jamais committer le fichier session.json dans Git — il contient vos tokens d'authentification. Ajoutez-le au .gitignore et stockez-le dans un volume Docker ou une variable d'environnement chiffrée.

Intégration dans un pipeline n8n

Ce script peut être déclenché automatiquement depuis n8n via un nœud Execute Command ou un webhook. La vidéo produite est ensuite uploadée sur Cloudflare R2 et l'URL sauvegardée dans Supabase.

  1. Déclencheur n8n (Schedule ou Webhook)

    Déclenche le workflow à chaque déploiement ou selon un planning défini.

  2. Nœud Execute Command

    node /scripts/capture-demo.js — Playwright + Xvfb enregistrent la démo en MP4.

  3. Upload Cloudflare R2

    La vidéo est uploadée via l'API S3-compatible de R2 avec un nom unique horodaté.

  4. Sauvegarde Supabase

    L'URL publique de la vidéo est insérée dans la table demos avec métadonnées (date, durée, hash).

  5. Notification

    Telegram ou email avec le lien direct vers la démo fraîche.
