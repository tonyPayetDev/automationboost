11 skills LinkedIn gratuits pour Claude

Vérifié le 7 septembre 2026·~5 min·open source, licence MIT

Le dépôt s'appelle sergebulaev/linkedin-skills : onze skills pour Claude Code, Codex et claude.ai qui écrivent tes posts LinkedIn, tes commentaires et tes réponses dans ta voix, retirent les tics d'IA, et n'envoient rien sans ton accord. Plus de 1 200 étoiles au 7 septembre, licence MIT, aucune inscription.

Ce que ça change

Chaque skill te montre un brouillon et attend. Rien n'est publié tant que tu n'as pas dit oui. C'est la bonne façon d'utiliser une IA sur un compte qui porte ton nom.

Ce que font les onze skills

  • Écrire un post à partir de formules de hook qui ont déjà fait leurs preuves.
  • Commenter le post de quelqu'un avec un vrai point de vue, pas un « super post ».
  • Répondre aux commentaires sous tes propres posts.
  • Optimiser ton profil : titre, résumé, mots qui comptent.
  • Planifier ta semaine : quoi poster, quand, avec qui interagir.
  • Analyser ton fil et ce qui marche autour de toi.
  • Humaniser : le skill le plus utile. Il retire les tirets longs, les mots qui sentent l'IA, puis passe ton brouillon dans plusieurs détecteurs d'IA pour que tu voies le score avant tout le monde.

La même équipe publie des bundles équivalents pour X, Instagram, YouTube, TikTok, Threads et Facebook, avec le même moteur de voix et la même règle « brouillon d'abord ».

Installer en deux minutes

Sur claude.ai

  1. Ouvre claude.ai/code, puis Skills dans la barre latérale.
  2. Clique Add from GitHub et colle : sergebulaev/linkedin-skills
  3. C'est tout : les skills s'activent seuls dès que tu parles de LinkedIn.

Sur Claude Desktop

  1. Customize → le + à côté de Personal plugins → Create plugin → Add marketplace.
  2. Add from a repository, colle sergebulaev/linkedin-skills, installe le plugin.
  3. Nouvelle conversation : « écris-moi un post LinkedIn sur… ».

Dans Claude Code

/plugin marketplace add sergebulaev/linkedin-skills /plugin install linkedin-skills@linkedin-skills

Ou, pour n'importe quel agent qui lit des fichiers SKILL.md : npx skills add sergebulaev/linkedin-skills

Trois demandes pour commencer

Écris-moi un post LinkedIn sur [ton sujet]. Ton direct, une idée, un exemple vécu. Montre-moi le brouillon avant.
Commente ce post : [lien]. Je veux apporter un angle que personne n'a donné, en trois lignes.
Audite ce brouillon : tics d'IA, tirets longs, mots vides, et ce que l'algorithme LinkedIn n'aime pas. [colle ton texte]

Deux limites honnêtes

Les actions qui touchent vraiment ton compte (lire des posts, publier) passent par des services tiers que les skills appellent : lis leur documentation avant de brancher tes accès. Et un post « humanisé » reste un post que tu dois relire : le score d'un détecteur d'IA n'est pas un avis de lecteur.
