Ce qui tourne vraiment chez un client

L'aperçu ci-dessus est instantané pour que vous puissiez tester librement. Chez un client réel, voici le workflow n8n complet qui se déclenche :

📝

Formulaire client

Le restaurateur remplit un formulaire en ligne avec ses plats du jour et ses préférences visuelles.

n8n Form Trigger
🧱

Génération HTML dynamique

Un template HTML sur mesure est construit avec les couleurs, la police et les plats — emojis détectés automatiquement.

Code Node · JavaScript
📸

Capture haute résolution

Le HTML est converti en image prête pour Instagram via une API de screenshot.

HTTP Request · HCTI
✅

Approbation par email

Le restaurateur reçoit l'image par email et valide, avec la date et l'heure de publication.

Gmail OAuth · Formulaire inline
📲

Publication automatique

Une fois validée, l'image est publiée sur Instagram à l'heure exacte choisie — sans intervention manuelle.

Blotato API · Instagram
